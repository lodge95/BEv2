# MyBizExchange — Java (Spring Boot + Thymeleaf) Clean Replica

This repo is a cleaned, modular Java/Thymeleaf implementation of the MyBizExchange public site.

## Quick start

Prerequisites:
- Java 17+
- Maven

Run locally:
```bash
mvn -B -DskipTests package
java -jar target/mybizexchange-0.0.1-SNAPSHOT.jar
